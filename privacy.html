Privacy Policy

Last updated: November 13, 2026

Wanted Level Tools is used only by its author to manage the author's own YouTube channels.

What data is accessed

With the author's permission, the tool reads and updates the author's own video metadata (titles, descriptions, tags, publish dates) and reads the author's own channel statistics via the YouTube API Services.

Storage and sharing

Access tokens are stored only on the author's own computer. No data is sold, shared with third parties, or used for advertising. No data from other users is collected.

Revoking access

Access can be revoked at any time at Google Account permissions.

The tool uses YouTube API Services; see the Google Privacy Policy.
